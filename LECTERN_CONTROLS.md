## Cadena de señal (audioEngine.ts)

```
fuente
  → pasa-bajos (BiquadFilterNode lowpass, 20 Hz – 20 kHz)
  → pasa-altos (BiquadFilterNode highpass, 20 Hz – 4 kHz)
  → distorsión dry+wet (WaveShaperNode + GainNodes)
  → phaser (4× BiquadFilterNode allpass + LFO + feedback delay)
  → pitch-shifter (2× DelayNode granular, crossfade con LFO)
  → eco / delay (DelayNode 0–4 s + feedback loop)
  → reverb (ConvolverNode, IR ~2.8 s)
  → ganancia maestra (GainNode, curva logarítmica)
  → AnalyserNode (FFT 256)
  → salida (AudioContext.destination)
```
